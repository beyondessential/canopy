# Sidebar navigation

## Sections

- [ ] Every section is listed in order, SQL only when the console is available
- [x] Incidents shows the open incident count while there are any
- [x] Public and Server Versions links appear after the sections and open in a new tab

## Pages within a section

- [x] The current section is expanded with its current page highlighted
- [x] Another section expands and collapses in place without navigating
- [x] Following Settings lands on Admins; following Fleet lands on Groups
- [x] A group's detail page keeps Groups highlighted
- [x] The healthcheck sources page keeps Healthchecks highlighted
- [x] Audit log is absent for a non-administrator

## Mode control

- [x] The mode band opens inline with the three modes and raises and lowers from there (verifies spec: SAFE)
- [x] Clicking elsewhere closes the mode menu
- [x] Closing the mode band's list by Escape, or dismissing the danger confirmation, returns focus to the band
- [ ] Dismissing the danger confirmation from the narrow top bar's mode control returns focus to it

## Narrow screens

- [x] Below the breakpoint the sidebar is hidden behind a menu button and the mode control is in the top bar
- [x] Following a link in the opened sidebar closes it
- [x] The narrow top bar links to incidents with the open count beside the mode control
